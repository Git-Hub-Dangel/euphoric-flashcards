### Card Syntax

The last `-` on a line always marks the translation. Everything before it is fair game.

| Operator | Behaviour |
|----------|-----------|
| `-` | Separates fields. Two `-` means the middle field becomes the explanation. |
| `:` | Adds an example sentence. Multiple allowed. |
| `=key` | Attaches a card type. Must be on the same line as other content. |

```
word - translation
word =type - translation
word : example - translation
word - explanation - translation
word - explanation : example : example =type - translation
```

#### Multiline

Use `--` in place of `-` and `::` in place of `:` to continue on the next line. `=type` goes on the last content line before the closing `--`.

```
word --
explanation ::
example =type --
translation
```

### Decks

- Register root tags under **Settings → Decks**, one per line (e.g. `#español`)
- Any subtag is a subdeck: `#español/verbs`, `#español/2026/week3`
- A card belongs to the nearest tag above it in the note

### Modes

Launch via Obsidian command `Euphoric Flashcards: Review`.

| Mode | Shows | Writes schedule |
|------|-------|-----------------|
| Review | Due cards only | Yes |
| Cram | All cards in deck | No |
| Sentence Builder | N words one by one, recall each in a sentence from memory | No |

### Review Responses

| Response | Effect |
|----------|--------|
| **Again** | Card re-enters the current session queue. On next correct answer, interval resets to 1 day. |
| **Okay** | Correct. Interval grows at a reduced rate. |
| **Good** | Correct. Full interval increase. |
| **Easy** | Cram only. Advances without touching the schedule. |

Desktop Keyboard Shortcuts
- `Space` = reveal
- `1` = Again
- `2` = Okay
- `3` = Good

### Settings

#### Decks
- **Root deck tags**: one per line, defines deck roots and their subdeck trees

#### Card Types

Define `key`, label, and badge colour. Use in cards with `=key`.

Built-in defaults:
- `n` noun
- `v` verb
- `a` adjective
- `p` phrase
- `i` idiom

#### Review
- **Show interval on buttons**: displ resulting interval (e.g. `4d`) on Okay and Good

#### Sentence Builder
- **Word count**: words drawn per session (1–17)
- **Word selection**: `Random` draws uniformly, `Optimised` draws roughly half mature words and the rest from newer ones

#### Scheduling

Hit **Restore Default Settings** to reset all values below to their defaults.

| Setting | Default | Notes |
|---------|---------|-------|
| Base ease | 250% | Starting ease factor for new cards |
| Easy bonus | 1.3 | Interval multiplier on Good |
| Lapse interval change | 0.5 | Interval multiplier after Again |
| Maximum interval | 36525 days | Hard ceiling on scheduled interval |
| Max link factor | 1.0 | Influence of linked note ease on card scheduling |
| Start of day | 00:00:00 | Due cards become available after this time |

#### Load Balancing
- **Load balance**: nudges cards toward less crowded days. Histogram rebuilds automatically every 24 h in the background.
- **Rebuild histogram**: triggers a manual full vault rescan. The last rebuild time is shown inline
